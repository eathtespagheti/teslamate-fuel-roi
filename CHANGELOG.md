# Changelog

## [0.1.2] - 2026-11-18

### Changed
- GitLab CI publishes release images as multi-arch manifests for
  `linux/amd64` and `linux/arm64` on `vX.Y.Z` tags.

## [0.1.1] - 2026-10-09

### Added
- GitLab CI publishes the container image to the GitLab Container Registry
  (`registry.gitlab.com/eathtespagheti/teslamate-fuel-roi`) on `vX.Y.Z` tags,
  using rootless BuildKit.

## [0.1.0] - 2026-10-09

### Added
- Initial extraction of the Italian MASE fuel-price importer and EV savings/ROI dashboards.
